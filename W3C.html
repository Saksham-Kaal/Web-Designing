W3C - World Wide Web Consortium

What is W3C?

W3C stands for World Wide Web Consortium. It was started in 1994 by Tim Berners-Lee, the inventor of the World Wide Web. Companies, universities and experts from many countries work together in it.

Purpose of W3C

The main purpose of W3C is to make rules (standards) for building websites. Because of these rules, a website works almost the same in Chrome, Firefox, Edge and Safari.

Important Work of W3C

  • HTML and CSS standards
  • Accessibility guidelines
  • Security and privacy

Conclusion

W3C is like a rule book for the web. We should follow its guidelines while making our websites.
